# Step1.什么是树？

- **什么是树**：树是一种非线性结构，节点与节点之间用边连接，具有层次结构。
- **如何定义一个二叉树**：二叉树即每个节点最多有2个孩子的树，可以使用结构体来定义一个树，其中包含节点变量。
- **二叉树在C语言中应该如何存储**：我们可以用结构体分别定义节点与树，同时可以仿照链表的形式将节点用指针连接，此时就存储了二叉树的树状结构。当然由于二叉树一般空间浪费率不高，我们也可以用数组来完成存储，只需要判断好哪些属于空节点即可。(树的层数越多，二叉树的浪费率会成指数增长)
- **二叉树的特点**：核心特点是每个节点最多有两个孩子，其中一个叫左孩子，一个叫右孩子，且左右不能调换顺序。

## 使用顺序表完成二叉树操作
1. 首先是初始化树，即将树中每个节点的数据都记为0，且将状态默认改为false，之后需要添加的更改为true即可。
2. 其次是创建根节点，这里我们从1开始，原因很简单，从1开始可以让后续创建孩子节点的操作一致，即左孩子就是$2i$，右孩子就是$2i+1$。
3. 创建左孩子与右孩子的方法类似，就是输入父节点数组下标后用对应的计算方法得到孩子的位置，然后带入输入的value。
4. 最后的层序遍历是卡住了我一会，我当时面临着几个问题：
> 第一是我要如何判断何时换行？
> 第二是如何避免把数组末尾几行的-1打印出来？
> 第三是怎么把-1和其他有效数据做好区分？

- 对于第一个问题，我其实原本想引入一个新变量n，然后对他从1到i时做循环，看i是否会在某个n时等于$2^n-1$（之所以是1到i是因为若n>i且n>1,则$2^n-1$必大于i），若会则说明i处于即将换行的位置，而这显然太过复杂。而AI给出了一个新知识：位与运算。通过位与运算我可以直接比较i与i+1在二进制下位数是否相同，若不同则说明i处于即将换行位置，这顺畅地解决了我面临的问题。
- 对于第二个问题，其实和第三个问题结合在一起就会很好解决，那就是找到最后一个有效数据，即false的节点不更新last，而true节点会更新last,如此我们就可以迅速找到在何处停止打印，避免打印数组最大容量下存储的一堆空节点。

# Step2.链二叉树

1. **创建节点函数**：跟第二题非常相似的操作，有了结构体的定义后，先申请动态内存，再对三个变量赋值，最后返回新节点。
2. 创建树的过程我就是简单粗暴的一步步列出来，同时按照次序将其用指针连接，这一步除了不是单链表外与上一题没有区别。
3. **不能直接打印的原因**：此处不能用`for`循环打印树，原因在于节点之间没有有序的标号，打印时做不到按照层序从上到下从左到右打印。

# Step3.递归

1. **前序中序后序遍历**：在三种递归中，其实逻辑本质都是一致，不同的是查看当前节点的时间：如果在一路向左孩子出发前查看当前节点，则是根左右，即先完成根节点打印再往左孩子走；如果是一路向左孩子走完了，也就是说走到最左下节点时打印当前节点，然后再往右孩子走，则是左根右，即左孩子走完了打印当前节点再走右孩子；若是先走完左孩子再走完右孩子再完成打印，则是左右根。这三种情况也对应了printf函数不同位置的情况。
2. **二叉树中递归过程**：以下图二叉树的前序遍历为例：
    - 进入`Preorder(root)`，打印根节点1,然后进入`Preorder(node2)`，打印2，再进入`Preorder(node4)`，打印4，进入`Preorder(NUll)`，此时发现为空，退出，回到`node4`，执行右孩子，又为空，结束`Preorder(node4)`。
    - 此时回到`Preorder(node2)`，走右孩子进入`Preorder(node5)`,完成打印和退出的过程，再退出`node2`，最后回到`root`。
    - 此时走`root`的右孩子，即`Preorder(node3)`，完成和上述基本相同的过程。

    **总结：递归过程就是不断往下深入，不断完成某一层后回到上一层级，直至将第一层都结束的过程。**

3. **统计树的深度**：一开始我没有看懂这个函数要干什么，问了一下AI后明白是通过递归来更新对树的深度的计算。结合要用到的两个参数不难看出要用`current_depth`来更新`max_depth`，那么很自然地面对题目中的问题：  
**为什么不需要用指针变量？**
原因其实就在在于函数是整型，所以每次递归都可以返回一个整数，这个整数就用来传递`max_depth`。如我的代码中所示，我们使前一层函数的`max_depth`等于下一层函数的返回值，那么由里到外就会将这个值传递回第一层，并且这个值是不断经过与`curren_depth`比较来确保其是最大的。[^1]
![1](https://github.com/backway-Lai/GLIMMER-CS-EASY-03/raw/main/images/screen-shot2.png)
[^1]:此处的`curren_depth`既不需要指针也不需要返回值，因为在每一次向孩子的移动中，这个值是固定的加一，因此我们完全可以在调用函数时就直接写明等于上一层的`current_depth + 1`。

4. **递归与循环**：首先循环与递归都是一定有终止条件的，且二者都是都有重复执行的特点。但两者的区别也很明显，虽然循环也是重复执行同一程序，但递归的函数调用使其可以对非线性关系的数据进行操作（如树），相对的，循环只能线性的进行重复。

5. **栈**：这部分的栈操作实际就是将前面递归部分的栈转变为人工的栈，用一个`stack`完成节点的存储，并且完成了正常的入栈出栈功能（即几个函数的使用）
